# Mini Assignment 5

## Instructions

- Integrate Processing with Sensor Data

- Work in teams of two. Using your assigned sensor, write an arduino sketch that takes in sensor data and transmits it to either Processing or [P5.js](http://p5.js). You may use Firmata + Processing, or Serial Communication with Processing / [P5.js](http://p5.js).
- Write an accompanying Processing or [P5.js](http://p5.js) sketch that takes in sensor data and uses it to change one or more visual properties of your sketch. This can be as simple as changing the background color of your sketch or more complex like graphing the data or using the sensor data to animate or generate graphical elements.
- Upload your modified example to your GitHub repo in a folder labeled "MiniAssignment5"
