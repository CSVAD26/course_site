# Assignments

Students are responsible for completing two mid-quarter projects and one final project. There will also be a series of mini assignments assigned throughout the quarter that build up to mid-quarter and final projects.

### [Mini Assignment 1](/assignments/mini-assignment-1)
Create a face through different means of image production

### [Mini Assignment 2](/assignments/mini-assignment-2)
Create a color-picker.

### [Mini Assignment 3](/assignments/mini-assignment-3)
Create a program to segment an image.

### [Mini Assignment 4](/assignments/mini-assignment-4)
Create a simple data visualization.


### [Project 1](/assignments/project-1)
Create a drawing tool.

### [Project 2](/assignments/project-2)
Create a data self portrait.

### [Final Project](/assignments/final-project)
Create an expressive work of computation.
